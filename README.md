# CodeHired

CodeHired is a web platform that helps developers find and apply for programming jobs. It brings job listings, search, and application tracking together in one place, so candidates can go from browsing to applying without bouncing between multiple sites.

## Features

- 🔍 **Job Search** — search and filter programming jobs by title, technology, location, or experience level
- 📄 **Job Listings** — detailed postings with role description, requirements, and company info
- ✅ **Apply Directly** — apply to jobs directly through the platform
- 📊 **Application Tracking** — keep track of jobs you've applied to and their status
- 👤 **User Profiles** — manage your candidate profile and resume
- 📱 **Responsive Design** — works across desktop, tablet, and mobile

## Getting Started

### Prerequisites

- _List required software, e.g. Node.js >= 18, npm, a database, etc._

### Installation

```bash
# Clone the repository
git clone https://github.com/Daniel-Pino-2000/CodeHired.git

# Move into the project directory
cd CodeHired

# Install dependencies
npm install
```

### Running the project

```bash
npm start
```

Then open `http://localhost:3000` (or your configured port) in your browser.
